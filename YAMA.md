# Форк для кампании «A, B, but C»

Ветка `yama`: доработки системы Dark Heresy 2E под кампанию. Сборка и выкладка — `utils/release.py` (`build`, `zip`, `local`, `server`). Апстрим — `upstream` (Vendare/DarkHeresy2E-FoundryVTT).

Тексты правил (качества оружия, таблицы критов, феноменов, Шока, злокачественностей и др.) в форке не хранятся: форк публичный. Их регистрирует модуль мира через `game.darkHeresy.registerQualityTexts` и `game.darkHeresy.registerTables`; без модуля механика работает, карточки показывают номера строк таблиц.

## Сделано

Бой:
- Урон по целям: кнопка в карточке урона, игрок применяет урон через ГМа (сокет системы); силовые поля (ОКП, с. 208–209, Таблица 5-13) — `script/common/damage.js`.
- Линейка движения по темпам Половинное / Полное / Атака / Бег, ограничение игроков Бегом за ход в бою — `movement.js`.
- Учёт полудействий и реакции по Таблице 7-1, передача хода — `actions.js`.
- Ситуационные модификаторы атаки по одной цели (ОКП, с. 283–285): дистанция по расстоянию между токенами, стрельба по цели в ближнем бою, лежачая / оглушённая / беспомощная / застигнутая цель, размер цели — `situational.js`.
- Оружие на броске атаки: заклинивание (обычное, Надёжное, Ненадёжное, очереди), перегрев, «Расклинить», штраф без Выучки, выбор зоны Меткой атаки; режимы атаки по скорострельности оружия — `weapons.js`, `dialog.js`.
- Площадные атаки: Взрыв (X) с разбросом при промахе, Распыляющее с уклонением Ловкостью и заклиниванием на 9, подавляющий огонь и Подавление — `area.js`, `pinning.js`.
- Состояния на самом персонаже (лежачий, оглушённый, горящий, Усталость), меню боевых действий Таблицы 7-1 (стойки, финт, манёвр, сбивание с ног, оглушение, захват), бой двумя оружиями — `conditions.js`, `combat-actions.js`, `two-weapon.js`, `ops.js`.
- Укрытия по Таблице 7-4 и модификаторы обстановки: темнота, туман и дым, непогода, возвышение, численный перевес, трудная местность — `cover.js`, `environment.js`.
- Качества оружия: подсказки с правилом, напоминания о проверках цели, при уроне — Гравитонное, Разящее (X), Погибель демонов, Мельта, Порченное — `qualities.js`.
- Черты: Сверхъестественная характеристика, Природная броня / Машина, Размер, Демонический, Страх с карточкой проверки — `traits.js`.
- Критические эффекты по таблицам с кнопками состояний, Праведная Ярость — `tables.js`.

Психосилы:
- Феномены и опасности варпа с модификаторами, Страх → Шок — `tables.js`.
- Зоны психического взрыва, поддержание с учётом действий и снижением ПР, дистанция силы, встречные проверки; шторм и шквал по правилам — `psychic.js`.

Рассудок и Судьба:
- Пороги Порчи и Безумия с проверками — `corruption.js`; злокачественности, мутации, травмы, расстройства с добавлением на лист — `mind.js`.
- Все траты и сжигание Судьбы, иммунитет к Страху по бонусу Безумия, Варп-шок — `fate.js`.

Вне боя:
- Первая помощь и кровопотеря — `medicae.js`.
- Реквизиция: Коммерция, встречная продажа, Жертва, Влияние инквизитора, количество, потеря Влияния; скрытая Секретность группы с журналом для ГМа — `requisition.js`.

Совместимость: устаревшие API v13–v14 заменены, к Foundry v15 готово по тому, что видно в v14; остаются листы на Application V1 (поддержка до v16).

## План

1. Демонология из «Врага потустороннего»: призыв, Владычество, сделки, одержимость, демонхосты, демоническое оружие.
2. Длительный уход и естественное лечение; окружение (падение, удушье, вакуум); персонажи поддержки за Влияние.
3. Перевод листов на ApplicationV2 и `messageMode` вместо `rollMode` — к Foundry v16.
