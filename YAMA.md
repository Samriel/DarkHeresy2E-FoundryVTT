# Форк для кампании «A, B, but C»

Ветка `yama`: доработки системы Dark Heresy 2E под кампанию. Сборка и выкладка — `utils/release.py` (`build`, `zip`, `local`, `server`). Апстрим — `upstream` (Vendare/DarkHeresy2E-FoundryVTT).

## Сделано

- Урон по целям: кнопка в карточке урона, игрок применяет урон через ГМа (сокет системы); силовые поля по ОКП (с. 208–209, Таблица 5-13) — `script/common/damage.js`.
- Линейка движения по темпам Половинное / Полное / Атака / Бег, ограничение игроков Бегом за ход в бою — `script/common/movement.js`.
- Учёт полудействий и реакции по Таблице 7-1, передача хода — `script/common/actions.js`.
- Качества оружия: подсказки с правилом (тексты регистрирует модуль мира через `game.darkHeresy.registerQualityTexts`, в системе текстов нет), напоминания о проверках цели в карточке нанесённого урона; при уроне — Гравитонное, Разящее (X), Погибель демонов, Мельта, Порченное — `script/common/qualities.js`.
- Площадные атаки: Взрыв (X) — круг на цели или в точке, разброс при промахе по Диаграмме Направлений; Распыляющее — конус 30°, уклонение Ловкостью (+20 без Выучки), заклинивание на 9; токены в зоне берутся целью, зона убирается после нанесения урона или при смене хода; дальность метательного оружия без своей — БС × 3 — `script/common/area.js`.
- Черты: Сверхъестественная характеристика, Природная броня / Машина, Размер (темпы и модификатор попадания), Демонический, Страх (карточка с проверкой) — `script/common/traits.js`.

## План

1. Русская локализация системы (`lang/ru.json`), включая новые строки форка.
2. Таблицы бросков: психические феномены, опасности варпа, критические эффекты; кнопки в карточках бросков.
3. Совместимость с Foundry v15: система использует глобальные классы, которые в v15 удалят (`ActorSheet`, `ItemSheet`, `Actors`, `Items`), и `migrateData` без возврата значения.
