# Форк для кампании «A, B, but C»

Ветка `yama`: доработки системы Dark Heresy 2E под кампанию. Сборка и выкладка — `utils/release.py` (`build`, `zip`, `local`, `server`). Апстрим — `upstream` (Vendare/DarkHeresy2E-FoundryVTT).

## Сделано

- Урон по целям: кнопка в карточке урона, игрок применяет урон через ГМа (сокет системы); силовые поля по ОКП (с. 208–209, Таблица 5-13) — `script/common/damage.js`.
- Линейка движения по темпам Половинное / Полное / Атака / Бег, ограничение игроков Бегом за ход в бою — `script/common/movement.js`.
- Учёт полудействий и реакции по Таблице 7-1, передача хода — `script/common/actions.js`.

## План

1. Качества оружия при уроне и подсказки по ним: правила качеств из ОКП (с. 179–185) во всплывающих подсказках на листе и в карточках; напоминания о проверках цели (Оглушающее, Токсичное, Зажигательное, Обездвиживающее, Валящее и т. д.) в карточке нанесённого урона.
2. Автоматизация черт: Природная броня (X) — к броне всех зон; Демонический (X) — к бонусу Выносливости при уроне; Сверхъестественная характеристика (X) — в поле Unnatural; Размер (X) — к темпам движения и модификатору попадания; Страх (X) — предложение проверки Силы Воли игрокам при появлении существа в бою.
3. Русская локализация системы (`lang/ru.json`), включая новые строки форка.
4. Таблицы бросков: психические феномены, опасности варпа, критические эффекты; кнопки в карточках бросков.
5. Совместимость с Foundry v15: система использует глобальные классы, которые в v15 удалят (`ActorSheet`, `ItemSheet`, `Actors`, `Items`), и `migrateData` без возврата значения.
